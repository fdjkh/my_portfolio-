Accessibility improvements:
1. Perceivable:
   - Alt text added to meaningful images.
   - Readable text and strong contrast.
   - Information is not dependent only on color.

2. Operable:
   - Keyboard-friendly navigation.
   - Visible keyboard focus.
   - Skip-to-content link.
   - Mobile menu can be operated with a button.
   - No automatic moving content.

3. Understandable:
   - Clear headings and navigation labels.
   - Consistent page structure.
   - Simple, readable content.
   - Descriptive links.

4. Robust:
   - Semantic HTML elements.
   - Proper language declaration.
   - Responsive design.
   - ARIA attributes for the mobile navigation.
   - Works with standard modern browsers.
